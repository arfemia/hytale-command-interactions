Hytale Update 6 compatibility. The jar runs on Update 6 (0.6.x) servers with no change to how
`RunCommand` works, and the worked block example matches how 0.6 makes a block usable.

- **Runs on Hytale Update 6 (0.6.x) servers.** Rebuilt for the 0.6 server line; nothing about the
  `RunCommand` step itself changed.
- **The block example matches Update 6.** A placed block is usable because its use interaction
  says so; the old usable-block flag is retired, and a pack still carrying it just logs a harmless
  warning in the server log. The worked examples in `README.md` and the CurseForge page drop the
  flag.
