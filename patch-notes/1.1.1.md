Command Interactions for Hytale's Update 7. The jar runs on Update 7 (0.7.x) servers with no change
to how `RunCommand` works. A server still on Update 6 stays on 1.1.0.

- **Runs on Hytale Update 7 (0.7.x) servers.** Rebuilt for the 0.7 server line, so the server loads
  it without the outdated-mod warning. Nothing about the `RunCommand` step itself changed.
- **A held item's `Ability2` and `Ability3` steps never fire on Update 7.** While an item is in your
  hand, Update 7 sends those two inputs to your slotted runes instead of to the item, so a
  `RunCommand` step on a held item's own `Ability2` or `Ability3` interaction never runs, and no log
  line says so. Put the step on `Primary` or `Secondary` instead. `Ability1`, `Ability4` and `Pick`
  still run the held item's own interactions, except for a player whose MMO Skill Tree ability slot
  sits on that input. The README's troubleshooting section has the details.
- **The example pack runs on Update 7.** Its potion takes the game's own drink cooldown, since
  Update 7 removed the stamina cooldown effect it used to apply. The example pack moves to 1.1.1
  with the jar.
- **Added the mod's own icon.** Command Interactions shows its icon in the game's mod list.
